# Minecraft Clone - Getting Started Tutorial

Welcome to the Minecraft Clone! This guide will help you get started with the game.

## First Time Setup

### Starting the Game

1. Open the game in your browser at `http://localhost:8000`
2. Click on the game window to start playing
3. Press ESC if needed to unlock the cursor

### Allow Pointer Lock

Your browser may ask for permission to lock the cursor. Click "Allow" to enable mouse look control.

## Basic Controls

### Movement
- **W**: Move forward
- **S**: Move backward
- **A**: Strafe left
- **D**: Strafe right
- **Space**: Jump
- **Shift**: Sprint (hold for continuous running)
- **Ctrl**: Crouch (hold to move slowly)

### Camera/Look
- **Mouse**: Move mouse to look around
- **Click & Drag**: Free look around the world

### Building & Interaction
- **Left-Click**: Destroy/break a block
- **Right-Click**: Place a block from your inventory
- **1-9**: Select block from hotbar
- **Mouse Wheel**: Scroll to select different blocks
- **C**: Pick block (copy the block you're looking at)

### UI & Info
- **H**: Toggle help menu
- **F3**: Toggle debug display
- **ESC**: Release cursor lock

## Your First Minutes

### 1. Look Around
- Move your mouse to explore the world
- Notice the blue crosshair in the center of the screen
- Observe the block outline when aiming at blocks

### 2. Breaking Blocks
- Look at a grass or dirt block
- Left-click to break it
- Watch particles fly out
- Notice the block disappears

### 3. Placing Blocks
- Break a few blocks to understand the mechanic
- Right-click near a block to place a new one
- The selected block (shown at top-right) will be placed
- You can't place blocks inside yourself

### 4. Inventory System
- Look at your hotbar at the bottom (9 slots)
- Click on different blocks to select them
- Use 1-9 keys for quick selection
- Scroll mouse wheel up/down to select

### 5. Navigate the World
- Use WASD to walk around
- Hold Shift to run faster
- Jump over obstacles with Space
- Explore to find different terrain types

## Game Mechanics

### Block Types

The world contains several block types:

**Building Blocks**:
- Stone (hard, gray)
- Dirt (brown)
- Grass (green top)
- Sand (yellow, near water)
- Wood logs (brown pillars)
- Leaves (green, from trees)

**Decorative Blocks**:
- Bricks (red)
- Clay (light gray)
- Gravel (speckled gray)

**Special Blocks**:
- Water (blue, flowing)
- Ores (darker blocks: coal, iron, gold, diamond)
- Bedrock (indestructible, bottom of world)
- Snow (white, in cold areas)

### Terrain Features

**Biomes**:
- Grass lands (most common)
- Sand desert (near water)
- Snow mountains (cold areas)

**Natural Structures**:
- Trees (oak and spruce)
- Water lakes
- Height variations
- Ore deposits

## Building Basics

### Creating Simple Structures

1. **Dirt House** (Easy)
   - Break grass blocks to get dirt
   - Place dirt blocks to build walls
   - Build a small shelter

2. **Tower** (Medium)
   - Collect blocks from different areas
   - Stack them vertically
   - Use right-click to place above previous blocks

3. **Bridge** (Medium)
   - Select a block type
   - Right-click in midair over water
   - Build a path across

### Building Tips

- You can place blocks next to existing blocks
- You cannot place blocks inside yourself
- Different block colors create interesting patterns
- Use different wood types for contrast

## Advanced Features

### Debug Display (F3)

Shows useful information:
- **FPS**: Frames per second (target 60)
- **Chunks**: Number of loaded chunks
- **Vertices**: Geometric data being rendered
- **Memory**: RAM usage
- **Particles**: Active particle effects

### Pick Block (C)

Quickly copy a block type:
1. Look at a block
2. Press C
3. That block becomes selected

### Audio Feedback

- Different sounds for different block types
- Jump has its own distinctive sound
- Block placement and destruction sounds differ

## Performance Tips

### If Game Runs Slowly

1. Reduce render distance in config
2. Close other browser tabs
3. Update GPU drivers
4. Check F3 debug display

### If Memory Usage is High

1. Lower particle limit
2. Reduce render distance
3. Clear browser cache
4. Restart the browser

## Troubleshooting

### Game Won't Start
- Check if JavaScript is enabled
- Try a different browser
- Clear browser cache
- Ensure WebGL 2.0 is supported

### Controls Not Responding
- Click on the game window
- Press ESC and click again to unlock cursor
- Reload the page
- Check if console has errors (F12)

### Low Frame Rate
- Reduce render distance
- Close other applications
- Update GPU drivers
- Check debug display (F3)

### Visual Glitches
- Reload the page
- Clear browser cache
- Try a different browser
- Update graphics drivers
